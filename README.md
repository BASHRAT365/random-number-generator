# Random Number Generator

A responsive random number generator built with HTML, CSS and JavaScript.

## Features

- Generate random numbers instantly
- Set minimum number
- Set maximum number
- Generate numbers within a custom range
- Input validation
- Responsive design
- Simple and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Live Demo

https://bashrat365.github.io/random-number-generator/

## Project Structure

random-number-generator/
├── index.html
├── style.css
└── script.js

## How It Works

The user enters a minimum and maximum number.

JavaScript uses Math.random() and Math.floor()
to generate a random whole number within the
selected range.
